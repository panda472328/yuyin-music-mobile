# 0.1.1 界面统一验证

验证日期：2026-10-08。手机版界面按 PC 版 0.4.9 的米白与鼠尾草绿风格统一。PC 仓库仍位于 `D:\音乐播放器`，版本和提交保持 `0.4.9` / `01b76bff9ee7e1f8b7d06459de6e6f4cbf71ffea`；本轮只修改独立的手机版仓库。

## 界面与回归

TypeScript 检查、11 项业务测试、11 项隔离手机界面检查和 4 项 Android 单元测试通过。界面检查使用虚构的歌曲、账号和原生接口，未访问用户账号；页面运行错误为 0。

截图逐项核对了登录、发现首页、搜索、歌词、歌单、账号菜单、设置和新建歌单弹层。品牌、字体、米白背景、绿系按钮及卡片、黑胶唱片和歌词高亮与 PC 风格一致。当前歌词句使用淡绿底、深绿粗体和圆点，触屏主操作保留至少 44 像素高度。

320 / 360 像素窄屏及 844×390 横屏的搜索与首页没有横向溢出；唱片不覆盖首页文案。播放页主要控件位于底部导航上方。收藏与歌单保存、歌词校准、队列切歌、收藏夹导入、保存失败处理、账号菜单和偏好重载均通过原有回归检查。

本机 UI 证据已归档到 `.qa/mobile-ui-0.1.1/`，其中 `evidence.json` 记录检查结果，各页面截图位于同一目录。它验证网页界面与保存处理，不代表真实 Bilibili 音频播放已验收。

## 模拟器覆盖安装

Android 9 / API 28 的 `emulator-5554` 上，使用 `adb install -r` 将正式 0.1.1 APK 覆盖原 0.1.0，再覆盖安装上述最终兼容修复包；安装成功，versionName / versionCode 为 `0.1.1` / `2`，初次安装时间保持不变。MainActivity 启动成功，无 AndroidRuntime 崩溃；未选歌曲的播放器空态能填满内容区并居中，未触发真实播放。

模拟器中已有账号会话，本轮保留其状态，不操作账号菜单、不登录或退出、不读取凭据，不清除应用数据。实际打开的发现页用于原生浅色主题验收；截图仅记录界面，账号头像区域经遮盖。该过程不算官方登录或真实 Bilibili 播放验证。

本机原生截图为 `.qa/mobile-android-release-0.1.1.png`，证据为 `.qa/native-ui-0.1.1-evidence.json`。发现页和米白状态栏已视觉核对；系统 UI 标志 `0x2010` 含深色状态栏 / 导航栏图标标志。模拟器没有显示底部 Android 系统导航栏，因此该条未作视觉验收。临时竖屏尺寸已恢复到原 Physical 1920×1080，无 override。

Android 7 / API 24–25 不能使用深色系统导航图标，导航栏配置为品牌绿背景；API 26 及以上通过资源覆盖使用米白背景。该兼容分支的实际显示仍需在对应旧版设备上核对。

页面与播放器高度已使用 WebView 91 支持的 `vh` 单位；100% 高度布局、歌词窗口、播放队列和弹层不依赖 `dvh`。

## 验证范围

本轮未改变 Android 音源服务、歌词接口或音乐库落盘机制。[0.1.0 验证记录](QA.md) 中的受控 Android 后台 / 熄屏播放和强制结束后存储恢复仍属于该版本的实际验证，未混记成 0.1.1 的真实 Bilibili 播放结果。本轮以界面回归、签名构建和安装启动为验证重点。

真实 Bilibili 登录与实播、手机长时间锁屏、省电条件，以及 Android 15 / 16 的系统边缘布局，仍需在相应手机上单独验收。
