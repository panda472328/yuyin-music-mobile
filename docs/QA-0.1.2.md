# 0.1.2 登录与后台播放修复验证

验证日期：2026-10-08。版本为 0.1.2 / versionCode 3；本轮只修改独立 Android 仓库。

## 修复范围

- 原生登录窗口只在官方 nav 确认当前账号有效、窗口和会话仍匹配后自动返回；原账号管理、验证挑战、失效 Cookie 和迟到回应有独立保护。
- React 在登录窗口返回后重新检查账号，合并会话变化与页面恢复请求，忽略旧请求结果；登录调用主动撤销此前的播放许可和歌词缓存。
- 服务专用音源 WebView 保持 Chromium 窗口可见性，当前官方视频页的隐藏状态受到保护；不通过强制复播覆盖用户暂停或音频焦点。
- 默认音源挂在播放服务自己的 64×64 私有窗口中，退出主 Activity 不再移除其窗口连接。原视频弹窗使用同一音源，返回后移回私有窗口；迟到旧弹窗回调不影响新弹窗。不新增悬浮窗或屏幕捕获权限，停止服务释放窗口、虚拟显示和帧队列。
- 原生音频焦点只在新源文档首次开始且媒体尚未播放时预检，已自行开始播放的页面跳过。同一文档暂停后恢复由 Chromium 管理焦点，避免重复原生请求造成延迟丢失而再次暂停；切歌与音源重建重新建立首次预检状态。

## 已完成的界面与业务检查

TypeScript 检查、17 项业务测试与 12 项隔离界面检查通过，页面运行错误为 0。新增回归覆盖迟到未登录回应、多个会话事件合并、旧会话失败不覆盖新成功、网络错误保留已验证状态、卸载后的异步回应，以及登录窗口返回但未收到会话事件时的登录门关闭。

界面验证使用纯虚构账号和曲目，没有注入真实 Cookie。本机截图与证据位于 `.qa/mobile-ui/`。业务与界面结果不代表原生登录或真实网络媒体已验收。

## 原生与安装包

本轮类型、业务、网页构建、Capacitor sync 和 Release / Debug / instrumentation 编译通过，4 项 Android 单元测试通过。原生设备回归已完成，具体范围与结果如下；最终干净源码签名 APK、构建提交、校验值与正式包覆盖安装仍待补充，不以 Debug 测试代替正式包验收。

## 本轮原生测试与实际结果

重现命令及跳过条件见 [Android 原生验证](ANDROID-TESTING.md)。本轮 5 项 instrumentation 测试全部通过，无失败、无跳过；以下计数与播放秒数来自 0.1.2 的本轮实际执行，不沿用旧版本结果。

| 检查 | 数量 | 实际结果与范围 |
| --- | --- | --- |
| `YuyinNativeContractTest` | 2 | 通过；插件方法、独立应用 ID 与非导出媒体服务 |
| `ControlledLoginTest` | 2 | 通过；官方 nav 格式解析，以及受控回调驱动实际 Android 登录 Dialog |
| `ControlledPlaybackTest` | 1 | 通过；自制 MP4 在正式服务中的完整媒体与生命周期流程，耗时 31.007 秒 |

登录测试使用虚构 UID 和受控官方响应，只通过私有结果处理入口验证窗口关闭与竞态保护，不注入 Cookie、不完成真实登录。它包含无身份 Cookie 的初始基准、已知同账号管理、未登录与验证挑战、旧会话签名、旧 Dialog、迟到基准响应，以及旧基准未知但新会话有效的流程。

媒体测试用自制 90 秒 H.264 视频与 AAC 音频 MP4，文件 195,200 字节、每 2 秒一个关键帧，并检查实际视频尺寸；播放结束另用短 WAV。正式音源页面的受控 HTML 包含隐藏时主动暂停的策略，测试读取实际媒体位置，检查桌面后台、熄屏、源控件暂停、后台 MediaSession 暂停/恢复、外部临时焦点中断、源视图重挂、Activity 重建和完全销毁。它还检查私有显示标志、旧源弹窗关闭回调保护，以及停止后窗口、虚拟显示和 Surface 释放。它拦截所有 HTTP 请求，不访问 Bilibili 音视频。

后台宿主使用公开 `VirtualDisplay` 与 `Presentation` API，只有本应用内容，没有屏幕镜像标志。64×64 `ImageReader` 收到帧后立即关闭，不读取或保存像素，避免输出队列堵塞。原视频 WebView 的正常重挂与最终销毁仍按公开生命周期执行，不延迟隐藏的系统 detach 回调；主 Activity 销毁时默认音源保留在服务的独立窗口中。

两个流程都使用继承 `MainActivity` 的 Debug 宿主，保留正式 Capacitor Bridge 与插件生命周期；Bridge 建立前即选择惰性 Debug 资产，不加载 React 或歌单界面。正式包不含该宿主、测试视频或测试注入接口。测试确认远程音源没有 Capacitor 桥接，音乐库与偏好 JSON 在流程前后完全一致。
