# UI 源码同步验证

日期：2026-10-15。PC 来源提交：`256d544ab8ffc680e6b661e0ee6b53c8d13a43fd`。手机版在 `0805454809a780e0d06e4688a47494906176742f` 的 0.1.4 源码上同步，不改变版本、正式 APK、签名和更新清单。本次提交不等于发布新版安装包。

## 改动

保留经典与系统明暗，更新 Bilibili 配色和我的世界灰色物品栏、斜边按钮与像素字体，提供触屏主题预览卡。播放页 / 设置可选择经典、聚光、手札、我的世界歌词预设，原生悬浮歌词独立选择；两者保留原来源与歌词校准。样式和原字体进入现有设置与 JSON 备份，旧数据默认经典。原生像素预设使用同字形 OpenType 字体，离开后恢复原字体；字号、颜色、透明度照常保留。

界面检查发现原歌词居中计算混用了不同 offsetParent，新增样式下当前句可能落在可见区外。现按实际元素边界计算滚动位置，并在字体加载 / 尺寸变化后重新居中；不 seek、不重启播放、不改时间偏移。

## 环境与边界

网页测试使用独立 Playwright 上下文、虚构歌曲和原生 facade；阻止外网请求，不使用真实账号。原生验证使用此前明确创建的专用实例 `OpenMusic-Playback-QA-20261015`（Android 9 / API 28，System WebView 91），测试前满足无账号、无日常歌库 / 偏好的前提，测试结束恢复受控测试数据，不清空真实用户 profile。

本轮没有确认真实 Bilibili 登录、网络搜索 / 评论、长时间播放或真机省电策略；Android 12+ 穿透与各厂商浮窗限制仍需对应系统验收。原生检查不代表全部 React 页面已在每款手机上人工测试。PC 的网页与 WPF 验证见 [PC 同步记录](https://github.com/panda472328/yuyin-music/blob/main/docs/QA-UI-SYNC-20261015.md)，其历史原生鼠标干扰限制保持原意。
