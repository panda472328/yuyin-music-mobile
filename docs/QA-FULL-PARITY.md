# PC 功能完整同步到 Android（2026-10-14）

| PC 功能 | Android 实现 |
| --- | --- |
| 歌名 / 视频搜索、联想、音乐 UP 优先、手动播放 | 已同步，连续结果列表；模式切换保留输入 |
| 经典 / Bilibili / 系统 / 像素主题、open音乐品牌 | 已同步，适配触屏导航与实际系统明暗 |
| 登录 / 游客、头像菜单、账号收藏夹歌单 | 手机独立 WebView 会话与原生账号校验 |
| 原视频评论、点赞、评论、回复和 MV | 已同步；MV 复用当前音源，不重载另一播放器 |
| 收藏、歌单编辑、历史和播放模式 | 手机私有存储；后台历史通过独立日志与界面保存合并 |
| 播放队列删除 / 清空 | 单曲菜单移除、确认清空；当前歌曲继续播放 |
| 静音后恢复音量 | 保存最后非零音量，旧音乐库读取时兼容迁移 |
| Bilibili 字幕 / LRCLIB、滚动、跳转、校准 | 已同步；来源和视频分别保存偏移 |
| 透明桌面歌词及字体 / 字号 / 颜色 / 透明度 / 位置 | Android 双窗口悬浮歌词；四种系统字体样式，三种颜色，原生触摸拖动、锁定穿透和中央解锁 |
| 歌词工具栏显隐 | 44dp 透明图标、窄屏横向滚动；轻触显示，3 秒后隐藏；锁定仅显示解锁 |
| 睡眠定时 | 原生服务保存绝对截止时间，15 / 30 / 60 / 90 分钟与取消；主界面销毁或熄屏后暂停 |
| 音乐库 JSON 备份 / 合并恢复 | Android 系统文件选择器；读取 PC JSON，移动备份额外包含主题、搜索模式、歌词校准和浮窗样式 |
| 持久化、损坏数据保护 | 正常保存等待落盘；读取失败阻止保存；显式恢复保留损坏原记录，原生一次提交歌库 / 设置 / 浮窗样式 |
| 后台媒体控制 | 原生自动续播、通知 / 锁屏 / 耳机上一首下一首；单曲循环时主动切歌仍换曲 |
| 键盘快捷键 | 实体键盘 Ctrl K、Space、Alt ← / →；文本输入不劫持 |
| 软件更新 | 前一轮已同步 Gitee 优先和 GitHub 回退；正式国内 APK 发布后才能启用国内稳定通道 |
| Windows 窗口、托盘、桌面快捷方式、EXE 安装器 | 由 Android 启动器、悬浮窗、媒体通知和系统 APK 安装界面适配；不复制 Windows 文件或几何状态 |

手机版备份限 8 MiB，先校验、预览，再合并去重；现有歌曲元数据与顺序保留，历史取每首最新时间，设置恢复需单独选择。PC 歌库 JSON 仅包含 PC 导出的歌库字段，不导入 PC 登录会话。没有新增跨设备账号或歌库自动同步。

原生服务使用相同视频 / 来源和校准值加载后台歌词；前台成功读取的时间轴可同步给服务缓存。异步歌词按视频、来源、媒体代次与账号会话隔离，过期结果不替换当前歌词。原生 LRC 与网页的正 metadata offset 均表示提前，用户正偏移均表示延后；支持重复时间标签、小时、毫秒和字幕结束留白。无字幕 / 无匹配歌词时不生成虚构歌词。

`ControlledParityTest` 实际执行系统文件选择窗口的打开 / 取消、ContentResolver 文件流读写与 UTF-8 / 容量拒绝、私有存储原子恢复与损坏记录保留、后台日志合并、MediaSession 前后切歌和自然续播、Activity 销毁后的缓存歌词恢复、熄屏睡眠定时。通过 UiAutomation 注入真实 Android 触摸验证浮窗拖动、字体切换、3 秒隐藏 / 重新显示、锁定仅一个中央解锁、文字穿透底层 Activity、解锁，以及屏幕旋转后的边界。歌词提供方测试使用受控传输，媒体测试预置合成歌词缓存，不发真实 Bilibili / LRCLIB 请求。

证据位于本机 `.qa/native-full-parity.log`、`.qa/native-full-parity-media.json`、`.qa/native-parity-locked-overlay.png` 和三套 UI 证据目录，不进入 Git。已检查新增设置、像素方角、备份弹层和真实锁定浮窗截图。另按 APK ZIP 内容与 DEX 字符串复核 Debug 包含 `qa-playback/index.html` / `QaPlaybackActivity`，unsigned Release 二者均不包含，结果位于 `.qa/release-isolation-full-parity.json`。
