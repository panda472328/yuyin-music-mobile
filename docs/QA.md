# 0.1.0 验证记录

验证日期：2026-10-08。手机版测试位于独立目录 `D:\音乐播放器-手机版`；下列结果来自业务测试和隔离的网页界面检查，未使用用户的真实 Bilibili 凭据，也不代表真实设备上的后台播放已通过。

## 已通过的检查

TypeScript `--noEmit` 检查通过。`tests/mobile.test.ts` 中 **11 项业务测试全部通过**：

1. 浏览器可用的 WBI MD5 与 UTF-8 参考值一致，覆盖填充边界和长字符串。
2. 保留 Bilibili 官方搜索顺序、解析视频信息，搜索不触发播放。
3. 未登录和验证挑战阻止搜索或播放，不伪装成功状态。
4. 会话变化使进行中的搜索失效，清理事件监听器有效。
5. 收藏、歌单、历史、队列和设置保存后重新读取一致；失败的保存不会替换原记录。
6. 损坏或不兼容的音乐库、设置记录显示错误并保留原内容。
7. Bilibili 字幕保留视频的时间戳与静音间隔，并提供 AI / UP 主来源标记。
8. 缺失字幕保持缺失状态；不支持的外部字幕地址被拒绝。
9. LRCLIB 根据歌曲和歌手匹配，避免把视频 UP 主误当成歌手。
10. 歌词偏移按歌曲和来源独立保存，默认 Bilibili 字幕提前 0.25 秒，保存值经过范围检查。
11. 收藏夹分页读取、重复视频去重，再次导入合并到同一份本地歌单。

隔离的手机网页界面检查 **11 项通过，未出现页面运行错误**：

1. 未登录时显示登录入口。
2. 搜索需要明确操作，结果不自动播放。
3. 收藏收到保存确认后更新。
4. 新建歌单与加入歌曲会保存。
5. 手动播放更新队列和播放历史。
6. 歌词校准保存偏移，不误触播放定位。
7. 上一首、下一首和结束事件按队列处理。
8. Bilibili 收藏夹导入成为独立歌单。
9. 保存失败显示错误，不把未保存的收藏显示为已完成。
10. 触屏账号菜单可用，收藏与设置在页面重载后保留。
11. 360 像素窄屏与横屏布局无横向溢出。

界面检查通过 Playwright 临时替换原生接口模块，在独立测试存储中驱动界面；登录、音源播放和网络歌词响应为测试夹具。该方式验证交互、布局和保存处理，不能证明真实 Bilibili 播放可用。其本机证据位于 `.qa/mobile-ui/evidence.json`，对应截图位于同一目录，这些临时文件不进入 Git。

## Android 源码审查

已检查原生服务的接口范围、来源页面导航和生命周期处理，并修正了审查中发现的问题：

- 网络请求限定在官方接口及指定字幕 CDN，Bilibili Cookie 只随 Bilibili API 请求发送；远程登录和音源 WebView 不暴露本地原生桥接。
- 登录会话变化使待处理的业务请求失效；播放服务在界面退出后仍检查原生会话变化，发生变化时停止旧音源。
- 初版音源和字幕对应视频第一分 P，切到其他分 P 会停止并提示重新选择，防止沿用不匹配的字幕。
- 临时音频焦点丢失保留恢复机会，旧焦点回调不会改变新的播放请求。
- 隐藏音源视图由服务持有，界面退出或重建时解除旧 Activity 的视图连接。

这部分为源码审查结果。Android 编译、原生测试、安装启动和系统媒体行为以以下实际执行记录为准。
